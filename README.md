# AI Summorise

Фоновое приложение для **Windows** и **macOS (Intel)**: суммаризирует выделенный текст и переводит текст
полностью локально — **Rust + Tauri 2 + llama.cpp** (через крейт `llama-cpp-2`), модель Qwen 4B в формате GGUF.
Ускорение: **CUDA** (Windows/NVIDIA), **Metal** (macOS), либо чистый **CPU**.

## Возможности

- Работа в фоне (иконка в трее, закрытие окна = сворачивание), опциональный автозапуск.
- Глобальные горячие клавиши (настраиваются в приложении):
  - `Ctrl/Cmd+Alt+S` — сводка выделенного текста из любого приложения;
  - `Ctrl/Cmd+Alt+T` — перевод выделенного текста (русский ⇄ английский определяется автоматически);
  - `Ctrl/Cmd+Alt+Space` — открыть окно.
- Вкладка «Сводка»: поле для текста, кнопка «Создать сводку», потоковый вывод, копирование, длина (коротко / средне / подробно) и язык сводки.
- Вкладка «Перевод»: отдельное поле ввода + перевод выделенного текста по хоткею, 14 языков.
- Окно контекста 8192–16384 токенов. Длинные тексты **автоматически делятся** на части (по абзацам → предложениям → словам),
  для каждой части строится промежуточная сводка, затем сводки **объединяются** (при необходимости в несколько уровней) в итоговый пересказ.
  Промежуточные сводки видны в интерфейсе.
- Скорость модели в нижней строке: генерация (ток/с), обработка промпта (ток/с), число токенов, время, устройство.
- Первый запуск: мастер предлагает скачать GGUF с HuggingFace в формате **Q4_K_M** или **Q8_0** (с докачкой, скоростью и ETA).
- Своя модель с диска: в мастере первого запуска и в «Настройки → Модель» есть кнопка «Выбрать файл…». Файл проверяется
  (сигнатура GGUF, размер), не копируется и используется по указанному пути; переключаться между ним и скачанными
  моделями можно в любой момент. Модель должна использовать шаблон ChatML (семейство Qwen).
- Управление ресурсами: модель **загружается только по запросу и выгружается сразу после генерации** (освобождаются RAM и VRAM).
  Необязательный режим «быстрого повторного запуска» держит модель в памяти заданное время простоя (1–60 мин).
  В трее и в шапке есть кнопка «Выгрузить модель».

## Про модель «Qwen 3.8 4B»

Официального Qwen3.8‑4B от команды Qwen нет (в семействе 3.8 официально выпущены только крупные модели). Существуют
community‑дистилляции под этим названием; по умолчанию используется
[`empero-ai/Qwen3.8-4B-Distill-GGUF`](https://huggingface.co/empero-ai/Qwen3.8-4B-Distill-GGUF) (Apache‑2.0, архитектура Qwen3.5‑4B;
`Qwen3.8-4B-Q4_K_M.gguf` ≈ 2.8 ГБ, `Qwen3.8-4B-Q8_0.gguf` ≈ 4.6 ГБ).
Как запасной вариант в списке есть официальный
[`unsloth/Qwen3.5-4B-GGUF`](https://huggingface.co/unsloth/Qwen3.5-4B-GGUF). Каталог моделей — в `src-tauri/src/models.rs`
(`PRESETS`), туда можно добавить любой другой GGUF в формате ChatML (Qwen).

## Сборка

### Требования

- Rust (stable), Node.js (для `@tauri-apps/cli`)
- **CMake** и компилятор C++ (Windows: Visual Studio Build Tools с «Разработка классических приложений на C++»; macOS: Xcode Command Line Tools)
- **LLVM/libclang** (нужен `bindgen`): Windows — `winget install LLVM.LLVM`, затем `LIBCLANG_PATH="C:\Program Files\LLVM\bin"`;
  macOS — входит в Xcode CLT
- Для CUDA‑сборки: **CUDA Toolkit 12.x**

### Команды

```bash
npm install

# разработка (CPU на Windows, Metal на macOS)
npm run dev

# релизная сборка: CPU (Windows) / Metal (macOS)
npm run build

# релизная сборка с CUDA (Windows + NVIDIA)
npm run build:cuda
```

Для macOS Intel: `rustup target add x86_64-apple-darwin`, затем `npm run build -- --target x86_64-apple-darwin`.
Установщики появятся в `src-tauri/target/release/bundle/` (NSIS для Windows, `.app` и `.dmg` для macOS).

### Сборка в облаке (GitHub Actions)

Если локальная сборка невозможна (например, Smart App Control в Windows блокирует неподписанные build-скрипты Rust),
используйте `.github/workflows/build.yml`. Он собирает три установщика: Windows CPU, Windows CUDA и macOS Intel (`.dmg`).

1. Загрузите проект в репозиторий GitHub (`.gitignore` уже исключает `node_modules` и `target`).
2. Вкладка **Actions → Build installers → Run workflow** (или отправьте тег `v0.1.0`, тогда установщики попадут ещё и в Releases).
3. Скачайте установщик из **Artifacts** завершённого запуска.

Первая сборка занимает 15–40 минут (компилируется llama.cpp, для CUDA — дольше), последующие быстрее благодаря кэшу.
Установщики не подписаны: Windows SmartScreen / Smart App Control и macOS Gatekeeper могут потребовать подтверждения запуска.

### Выбор вычислительного устройства

Бэкенд определяется на этапе сборки (флаг `cuda`; на macOS Metal включается автоматически), а в настройках
доступно «Авто (GPU, если доступен)» или «Только CPU». Если загрузка на GPU не удалась (например, не хватило VRAM),
приложение автоматически перезагружает модель на CPU. Практически: собирайте `build:cuda` для NVIDIA‑машин и обычный
`build` для остальных; CUDA‑сборка требует установленного драйвера NVIDIA и CUDA‑рантайма (DLL `cudart`/`cublas` рядом с exe или в PATH).

> Нюанс: сам CUDA‑контекст процесса (около 200–400 МБ VRAM) освобождается только при завершении приложения.
> Веса модели и KV‑кэш освобождаются полностью сразу после генерации.

## Как это работает

| Файл | Назначение |
|---|---|
| `src-tauri/src/llm.rs` | загрузка/выгрузка модели, генерация, подсчёт скорости, фильтр `<think>` |
| `src-tauri/src/job.rs` | промпты, map‑reduce суммаризация, перевод по частям, события для UI |
| `src-tauri/src/chunking.rs` | разбиение текста на части (с юнит‑тестами) |
| `src-tauri/src/models.rs` | каталог моделей, загрузка с HuggingFace с докачкой |
| `src-tauri/src/selection.rs` | захват выделения: эмуляция Ctrl/Cmd+C → чтение буфера → восстановление буфера |
| `src-tauri/src/hotkeys.rs` | регистрация глобальных хоткеев |
| `src-tauri/src/lib.rs` | команды Tauri, трей, фоновый таймер выгрузки |
| `ui/` | интерфейс (HTML/CSS/JS без сборщика) |

Данные: настройки — `settings.json` в каталоге конфигурации приложения, модели — в `<app data>/models`
(кнопка «Открыть папку моделей» в настройках).

## Замечания

- **macOS:** для захвата выделения приложению нужно разрешение «Универсальный доступ» (Системные настройки → Конфиденциальность).
  Без него хоткей откроет окно без текста.
- Захват выделения временно использует буфер обмена и затем восстанавливает **текст**; изображения/файлы в буфере не сохраняются.
- Если сочетание занято другим приложением, в настройках появится предупреждение — выберите другое.
- Подпись/нотаризация macOS‑сборки и подпись установщика Windows в проект не входят.
